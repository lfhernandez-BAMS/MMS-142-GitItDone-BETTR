How to edit files in github (no need to upload an updated file):
 1. open the file to be edited
 2. click on the pencil button at the top-right corner of the file preview
 3. edit the file by either direct edit or copy and paste from a source
 5. once finished editing, click on the "Commit Changes"

Updating a file via uploading:
 1. click on the add file button
 2. upload existing file
 3. make sure that the filename of the new file matches the old file
